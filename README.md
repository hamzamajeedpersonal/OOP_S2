# 💻 Object-Oriented Programming (Semester 2)

---

##  Repository Objectives
* Practice fundamental and advanced OOP concepts in Java.
* Implement data hiding, abstraction, and clean coding principles.
* Maintain a structured record of lab exercises and practical implementations.

---

## 📚 Topics Covered

### 1. Fundamentals & Encapsulation
* Classes, Objects, and Access Modifiers (`private`, `public`, `protected`)
* Data Hiding & Validation using Getters and Setters
* Constructors and Variable Scopes

### 2. Inheritance & Code Reusability
* Single and Multi-level Inheritance
* Method Overriding and the `super` Keyword
* Class Hierarchies

### 3. Polymorphism & Flexibility
* Method Overloading (Compile-time Polymorphism)
* Method Overriding (Runtime Polymorphism)
* Dynamic Method Dispatch

### 4. Abstraction & Interfaces
* Abstract Classes and Abstract Methods
* Interfaces and Multiple Inheritance implementation
* Loose Coupling & Modular Design
